# Personal-Project
This repository is a space where I will put my personal developing project. These projects can consist of game, management, or calculation !
1) My first game is the word guessing - Hangman game! (5/29/2026)
- This project was built mainly by using C++ only.
- It was a logic game where I had to combine control structures or flow control statements. The game was constructed with function, if - else statement, and loop. Currently, the game can access to file and allow player to choose a random word that they will guess. The project lets the user to guess 20 times until they run out of chances and end the game.
- The most specific function, which I think is cool, is that it can swap the letter into order even when the player guess the word randomly, it will go in order. However, it is not completely perfect. Some words can not arrange in their right order or some letters can be missing.
*UPDATE: I changed the algorithm where we had to choose a random number to get the word. I used srand algorithm in C++, so that it could generate random number to choose the word in the array.
2) Calculator Project (6/1/2026)
- This project is an easy one that performs solving calculation with two input numbers. It can do +, - , *, /, trigonometric function, sqrt, and power.
- However, it can only calculate 2 numbers. (I was trying to do a calculator program that can take more numbers but it failed completely TvT).
3) Casino Project - Roulette (6/4/2026)
- This project is also a guessing game like the Hangman project, but in a casino format. Moreover, in this project, the player can bet money. If they guess the number right, they will receive the amount of money collected based on the amount of number they guessed right. If they guess any number wrong, then the amount of money in the bet will be subtracted from the balance.
- Player can keep on betting with the amount of money which they have collected from previous matchss (In this game, the amount of bet will be considered as the amount of money that the player has).
